# LG webOS

This integration controls an LG webOS TV locally from Gladys Assistant.

## Setup

1. Give the TV a fixed IP address (or static DHCP lease).
2. Enter its IP and MAC address in the integration configuration.
3. Keep the connection mode on **Automatic**.
4. Turn on the TV and click **Test TV connection**.
5. Accept the pairing prompt displayed on the TV. Gladys then keeps the pairing key.

The first version exposes power, volume, mute, play/pause/stop, volume +/-, channel +/- and toast notifications.
